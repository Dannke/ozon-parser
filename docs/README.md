# Документация

Документы разложены по назначению: руководства — как сделать конкретную
задачу, справочник — точные параметры и форматы, объяснения — почему система
устроена именно так.

## Руководства

| Документ                                 | Когда открывать |
| ---------------------------------------- | --------------- |
| [installation.md](installation.md)       | Установить окружение, настроить `.env`, Gmail и сессию Ozon |
| [operations.md](operations.md)           | Ежедневный запуск, мониторинг, логи, Docker, типовые проблемы, секреты |
| [legacy.md](legacy.md)                   | Старый сценарий: `parse_ozon.py` по списку, Airflow, контроль среза |
| [development.md](development.md)         | Тесты, линтер, проверка типов, новые миграции |
